# @ifonso/mylab-theme

[![Github Actions Status](https://github.com/ifonso/mylab-theme/workflows/Build/badge.svg)](https://github.com/ifonso/mylab-theme/actions/workflows/build.yml)

A JupyterLab minimalist theme based on [RStudio](https://posit.co/products/open-source/rstudio/) and [Datalore](https://www.jetbrains.com/datalore/). I didn't want to pay for Datalore and I've always loved using Jupyter in my local environment, but the visuals became kinda boring since I started using RStudio for some things, so I changed it to my taste, based on the visuals that I like. It's not perfect, but it looks amazing on my OLED display. If you ask, yeah, light mode. I might be a psychopath, that's why I became a data analyst. Happy hacking, hope you like it.

> Still an experimental theme. Any problems, please open an issue.

## Requirements

- JupyterLab >= 4.0.0

## Install

To install the extension, execute:

```bash
pip install mylab-theme
```
